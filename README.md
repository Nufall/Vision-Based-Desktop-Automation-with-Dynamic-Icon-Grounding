# Vision-Based-Desktop-Automation-with-Dynamic-Icon-Grounding
Locate the Notepad icon anywhere on a Windows desktop, double-click it, and use it to save 10 blog posts pulled from the JSONPlaceholder API. The grounding step is **vision-only** — no Win32 enumeration of desktop icons, no hardcoded coordinates. The same pipeline works regardless of where the icon is on the desktop.
